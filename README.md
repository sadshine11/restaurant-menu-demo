# Меню ресторана — демо интерфейса

Демонстрация веб-приложения «Меню ресторана с корзиной»: показывает логику работы будущего сайта до начала разработки.

**Демо:** https://sadshine11.github.io/restaurant-menu-demo/

## Что можно проверить

- вывод блюд по категориям (салаты, горячее, десерты, напитки) через табы с подгрузкой без перезагрузки страницы;
- мини-корзина в шапке: количество позиций и сумма обновляются сразу;
- корзина: изменение количества, удаление позиций, автоматический пересчёт суммы;
- оформление заказа с формой доставки;
- личный кабинет с историей заказов: состав, дата, сумма, статус;
- вход в двух ролях — клиент и администратор;
- панель администратора: добавление, редактирование и удаление блюд с полями название, описание, цена, категория, изображение;
- схема базы данных из пяти связанных таблиц внизу страницы.

## Важно

Это демонстрация интерфейса на одной HTML-странице, данные хранятся в браузере.

В рабочей версии: PHP и MySQL, корзина в сессии, таблицы `users`, `categories`, `dishes`, `orders`, `order_items`, пароли в виде хеша, загрузка изображений с проверкой формата и веса, подготовленные запросы к базе.
