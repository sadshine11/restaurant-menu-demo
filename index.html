Панель администратора

Раздел доступен только пользователю с ролью «администратор». Добавление, редактирование и удаление блюд — изменения сразу видны в меню.

Структура базы данных

Пять связанных таблиц по вашему техническому заданию. Цена в order_items фиксируется на момент заказа, поэтому история заказов не меняется при изменении цен в меню.

users

  • id PK
  • name
  • email unique
  • password_hash
  • role client / admin
  • created_at

categories

  • id PK
  • title
  • slug unique
  • sort_order

dishes

  • id PK
  • category_id → categories.id
  • title
  • description
  • price
  • image
  • is_active

orders

  • id PK
  • user_id → users.id
  • total
  • status
  • phone
  • address
  • created_at

order_items

  • id PK
  • order_id → orders.id
  • dish_id → dishes.id
  • qty
  • price на момент заказа
